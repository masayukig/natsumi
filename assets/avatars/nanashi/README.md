# 名無しのアバター

顔の無い、組み込みのアバターです（ADR 0057）。config の `avatar.id` に `nanashi` と書けば、これになります。
ほかのアバターに足りない素材（spritesheet と動作の定義、表情のアイコン、Slack の PNG）を埋める元でもあり、
`sdctl-params.yaml` は、自分の params を持たないアバターが使うサーバーの既定の params です。

| ファイル | 内容 |
| --- | --- |
| `avatar.json` | ID（`nanashi`）と表示名（名無し）、1 マス 192×208、1 列 × 1 行、`idle` の 1 フレームだけ。どの表情も `idle`（`angry` を含む） |
| `pet.json` | Codex のペットの形式の定義 |
| `spritesheet.webp` | 顔の無い人形の 1 コマ |
| `icons/<表情>.webp` | 表情ごとの顔（512×512）。仕様の 9 つ（`angry` を含む）。どれも同じ、顔の無い人形 |
| `slack/<表情>.png` | Slack のアイコン（256×256） |
| `sdctl-params.yaml` | 画像生成の既定の params（Anima の汎用の設定） |

`appearance.yaml` は置いていません（決まった姿は無い）。

欠けの無い完全なアバターにしておきます。サーバーの改修でアバターの素材が増えたときは、ここにも同じ素材を足します。

**今の画像は仮のものです。** 灰色の丸と胴だけの、顔の無い人形を Pillow で描いたものです。
本人が用意するのっぺらぼうの絵に差し替えます。差し替えても、ファイルの名前と大きさはこのままにします。
