# ミャオのアバター

組み込みのアバターです。config の `avatar.id` に `myao` を指定すると、名前と姿がミャオになります。
ファイルの仕様は [アバターの作り方](../../../docs/avatar.md)、制作手順は [CLAUDE.md](../CLAUDE.md) を参照してください。

直下の PNG は新しく生成した表情 9 枚です。`icons/` は顔の 512×512 WebP、`slack/` は同じ切り出しの 256×256 RGB PNG です。
`avatar.json` と `pet.json` が動作を定義し、`appearance.yaml` と `sdctl-params.yaml` が描画の既定値を持ちます。

## 出どころと生成設定

表情はすべて sdctl、モデル `anima_anima-base-v1.0`、LoRA `myao_anima.v1`（強度 1、トリガー語 `myao`）で生成しました。
基本プロンプトは `1girl, normal skin, yellow shirt, <lora:myao_anima.v1:1>, myao,`。
品質の行は伊織のものから `(realistic:0.5)` を外し、表情と白背景・アイコン・顔のクローズアップを加えています。
Negative は伊織のものに `(human ears, extra ears, normal ears, realistic ears:1.7),` を加え、猫耳だけにしています。

- 896×1152、ER SDE、Beta、Steps 32、CFG 4。
- モジュール: `qwen_image_vae.safetensors`、`qwen_3_06b_base.safetensors`。
- Model hash `bd43b7cffe`、LoRA hash `4149df156193`。
- Shift 3.5、Beta の alpha/beta はともに 0.6。sdctl の params にこれらの専用欄がないため、WebUI 側の値に依存します。
- 詳細なプロンプトと生成メタデータは各 PNG の `parameters` に保存しています。
- 表情ごとに候補を 2 枚ずつ比較し、髪・瞳・耳の一貫性と表情の読み取りやすさで選びました。

## 外見

描いた画像では淡い青灰色の短い髪、琥珀色の瞳、大きな猫耳を確認できました。
本人の確認により、`keep` は `pale blue-gray hair`・`amber eyes`・`cat ears` の3つに決定しました。
髪の長さは固定しないため `short hair` は外しています。描く前の確認で特徴の語を照合できるよう、`keep` の3語は `body` の体の行にも含めています。
顔の画像では尻尾を確認できないため `keep` に入れていません。

## アニメーション

spritesheet は Codex の `hatch-pet` と OpenAI の画像生成で作成しました。
正面に近い `neutral.png` を参照して、黄色いシャツ、暗い色の短パンと靴を着た小さな全身像を生成し、共通の参照にしています。
各動作は共通の全身像と元の顔、コマの配置ガイドを参照して個別に生成しました。
右移動には歩幅の変化があり、左右で意味が変わる柄や小物がないことを確認してから、左移動を各コマの左右反転で作っています。コマ順は保持しています。
元の横長画像ではコマ間隔が均等でないため、右移動を抽出したあとのセルを hatch-pet の反転処理に渡し、左移動で隣の髪が切れて混ざることを避けています。

動作とフレーム数は `idle` 6、`running-right` 8、`running-left` 8、`waving` 4、`jumping` 5、`failed` 8、`waiting` 6、`running` 6、`review` 6 です。
`running` はその場で考える作業中の姿、`review` はあごに手を置いて確認する姿です。
表情と動作の対応は伊織・なつみに合わせ、`angry` は `failed` にしています。

背景除去の閾値は 160、抽出は `stable-slots` です。動作内の縮尺を共通にし、ジャンプの上下動とうつむく動作を保っています。
透過境界から4ピクセル以内で青成分が赤・緑の最大値を12より多く上回る画素だけ、青成分をその最大値に合わせて青い縁を補正しました。アルファ値と輪郭内部の髪色は保持しています。
全コマの確認用画像と動作プレビューで、同じ外見・動作・切れ・透過を確認しています。確認用画像は素材に含めていません。
