# 0054. ダッシュボードで、なつみの作業環境・記憶・マニュアルのファイルを読み取り専用で見る

- Date: 2026-09-27
- Status: Accepted

## Context

[ADR 0049](0049-a-read-only-dashboard-in-the-browser.md) のダッシュボードで、本人はターンごとの思考やツールの呼び出しを追えるようになった。
一方、なつみが何を書き、何を作ったかは、ファイルの側からは見えない。
ターンの詳細に `read` の引数のパスが出ても、その中身は開けない。本人は、なつみの作業環境（`/work`・`/home/natsumi`）、記憶（`/memory`）、マニュアル（`/manual`）の中身をブラウザで確かめたいと考えた。中身はほぼテキストと画像である。

手元の事情は次のとおりである。

- サーバーは data directory の `memory/`（記憶の git。`loop.memoryRepository` で別の場所にもできる）・`work/`・`home/`・`agents/`（作業環境では `/manual/agents`）を直接読める（[ADR 0019](0019-a-workspace-not-a-memory-tool.md)、[ADR 0036](0036-a-manual-to-read-and-a-limit-on-waiting.md)）。
- `/manual` はリポジトリの `manual/` を作業環境の image に焼いたものであり、サーバーの image には無い。
- なつみは作業環境で symlink を作れる。サーバーがそれをたどると、閉じ込めの外（サーバーの設定や token、SQLite）を指すものも開けてしまう。
- SVG と HTML は、ブラウザにそのまま出すとスクリプトを運べる。`memory/.git` と隠しファイルは数が多く、一覧を埋める。`/home/natsumi` には、なつみが作った設定のファイルが混ざる。
- ファイルは大きいことがあり、HTTP の処理の中で同期に読むと、思考ループと WebSocket を止める。

設計は grill-me（Q1〜Q8）で詰めた。

## Decision

### 見せる場所

- `/memory`・`/work`・`/home/natsumi`・`/manual`・`/manual/agents` の 5 つを見せる。URL は `/dashboard/files` の後に作業環境のパスをそのまま続けた形とする。
  作業環境でのパスと閲覧の URL が 1 対 1 に対応し、ターンの詳細からのリンクも組み立てやすい。
- `/memory` は記憶の repository（`loop.memoryRepository`、既定は data directory の `memory/`）を読む。
- `/manual` は、サーバーの image にもリポジトリの `manual/` を COPY し、それを読む。作業環境の image と同じビルドから作るので、中身は同じである。
  - 置き場所は設定にしない。コードに同梱の静的ファイル（ダッシュボードの CSS と JS）と同じく、コードの位置から決める。チェックアウトから起動したとき（`--data-dir` で data directory を指すとき）は、チェックアウトの `manual/` を読む。
  - `/manual/agents` は data directory の `agents/` を読む。作業環境で `/manual/agents` が上からマウントされるのと同じく、`/manual` の中の同名のものより優先する。
- 記憶の変更履歴（コミットの一覧・diff）は今回は入れない。今の中身だけを見る。必要になったら別に決める。

退けた案:

- **`/memory` と `/manual` だけ**: 成果物や画像が見えない。
- **`/home/natsumi` を外す**: 作業の跡を確かめられない。見せる相手は本人 1 人であり、守りはダッシュボードの認証で足りる。

### 閲覧は読み取り専用で、ダッシュボードの認証をそのまま使う

- ADR 0049 の cookie の認証、読み取り専用、サーバーで HTML を組むこと、全エスケープと CSP を引き継ぐ。書き込み・削除・名前の変更などの操作は置かない。
- 一覧は 1 階層ずつ出す。ディレクトリの中身の大きさを再帰で数えることはしない。
- 並びは名前順（ディレクトリが先）を既定とし、列見出しの「名前」「更新日時」「大きさ」で、クエリにより並べ替える。JS は使わない。
- パンくずで上の階層に戻れるようにする。
- ファイルの読み込みはすべて非同期で行う。同期の読み込みで思考ループを止めない。

### symlink はたどらない

- 一覧では、symlink を「→ 指す先」として出すだけにし、開けない。
- パスの途中の要素が symlink の場合も断る（`/work/d` が `/etc` を指していても、`/work/d/passwd` は開かない）。
  パスの要素を 1 つずつ symlink でないことを確かめ、開いた後にも、実際の場所がルートの内側の同じファイルであることを照合する。
- `..`・絶対パス・エンコードされた区切り（`%2F`）・空の要素・NUL などで、ルートの外に出る URL は受け付けない。
- ルートそのもの（data directory の `work/` など）は、設定したとおりの場所を実際のパスにしてから使う。

退けた案:

- **ルートの内側を指す symlink だけたどる**: 確かめてから開くまでの間の差し替えへの手当てと、そのテストが増える。必要になったら広げる。

### 隠しファイルと `.git`

- `.` で始まるものは既定で一覧から隠し、「隠しファイルを表示」（クエリ）で出す。開くことは、どちらでもできる。
- `/memory` の直下の `.git` は、どちらでも出さず、開くこともできない。

### ファイルの見せ方

- テキストは先頭の約 1 MiB だけを出し、それより大きければ「以降は省略（全体の大きさ）」と書く。
- 画像は PNG・JPEG・WebP・GIF だけを、ダッシュボードの認証付きの URL で表示する。種類は拡張子ではなく中身の先頭のバイトで決める。
- SVG と HTML はテキストとして出す。その他のバイナリは種類と大きさだけを出す。
- テキストかどうかは、先頭に NUL を含まず、UTF-8 として正しく読めることで決める。
- Markdown は、既定でサーバーで整形して出し、クエリで生のテキスト（エスケープして `<pre>`）に切り替えられる。整形にはライブラリを 1 つ足す（markdown-it）。
  - Markdown の中の生の HTML は通さず、エスケープする。
  - リンクは `http`・`https` と、ルートの内側の相対パスだけを残す。相対パスは閲覧の URL に書き換える。ほかのリンクは文字だけにする。
  - 画像の埋め込みは、ルートの内側の相対パスだけを認証付きの URL に書き換える。ほかは出さず、代わりの文字だけを出す。CSP の `img-src 'self'` でも止まる。
- どのファイルにも「ダウンロード」を置く。`Content-Disposition: attachment`・`application/octet-stream`・`X-Content-Type-Options: nosniff` で返し、ストリームで読む（メモリに全部を載せない）。

退けた案:

- **Markdown を生のテキストだけで出す**: 読みにくい。**整形だけ**: なつみが書いた文字列そのものを確かめられない。
- **表示だけでダウンロードを置かない**: 省略した残りやバイナリを取り出せない。

### ターンの詳細からのリンク

- ターンの詳細で、組み込みのファイルのツール（今は `read` だけが有効である）の引数のパスが上の 5 つの場所の内側なら、そのパスを閲覧へのリンクにする。
  相対パスは、作業環境の作業ディレクトリ `/work` から解決する。
- リンクの横に「今の中身であり、そのターンの時点のものではない」と書き添える。
- `run_shell` のコマンドや、ツールの結果の本文の中のパスは拾わない。取りこぼしと誤ったリンクが増えるからである。

### ADR との関係

- ADR 0049
  - 追加: 画面に並べるものに、なつみのファイルの閲覧を加える。認証・読み取り専用・CSP・サーバーで HTML を組むことは、そのまま使う。
  - 追加: Markdown の整形のために依存を 1 つ足す。整形した HTML は、生の HTML を通さない設定で作り、リンクと画像を上の規則で書き換えたものだけを載せる。
- ADR 0036
  - 追加: サーバーの image にも `manual/` を置く。作業環境の `/manual` と同じ中身を、サーバーが読むためである。

## Consequences

- 本人は、なつみが書いた記憶、作ったファイルや画像、マニュアルを、ブラウザで今の中身のまま確かめられる。
- ブラウザに出る個人データの範囲が、ターンの記録から、記憶と作業環境のファイルの全体に広がる。`/home/natsumi` のなつみが作った設定のファイルも含む。
  守りは ADR 0049 と同じ（GitHub ログインと許可ユーザー 1 人の照合、`HttpOnly` の cookie、全エスケープと CSP）に、symlink をたどらないことを加えたものである。[権限と秘密の一覧](../permissions.md)に入口を足した。
- symlink の先は見えない。なつみが symlink で整理した場所は、指す先のパスを見て、その場所を開き直す必要がある。
- 確かめてから開くまでの間に、なつみがパスの途中を symlink に差し替える余地は、開いた後の照合で断る。
- ターンの詳細からのリンク先は今の中身であり、そのターンの時点のものではない。書き換えや削除の後は、別の中身か「見つかりません」になる。
- サーバーの image に `manual/` が増える。作業環境の image との中身の食い違いは、同じビルドから作る限り起きない。
- Markdown の整形の依存が 1 つ増える。
