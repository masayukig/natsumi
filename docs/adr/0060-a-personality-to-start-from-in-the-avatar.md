# 0060. 性格・話し方の初期値をアバターのディレクトリに置く

- Date: 2026-09-29
- Status: Accepted（アバターの `personality.md` を config の `avatar.personality` で丸ごと置き換えることは [ADR 0057](0057-an-avatar-directory-named-in-the-server-config.md) の config の節で追加）

## Context

natsumi の性格と話し方は、記憶のリポジトリの `personality.md` にある（[ADR 0018](0018-memory-in-git-and-the-nightly-rebuild.md)）。
session を作るときにプロンプトに入り、夜の再構成のときだけ natsumi 自身が書き換えられる。日中のターンでの変更は戻る。

このファイルは、記憶のリポジトリに無いときだけ、サーバーが作る。
旧配置（data directory の直下）に `personality.md` があればそれを移し、無ければコードに固定の枠（「natsumi の性格と話し方をここに書きます。」）を置く。

最初の性格を決める手段が無い。config にも、アバター（[ADR 0057](0057-an-avatar-directory-named-in-the-server-config.md)）にも欄が無い。
本人が決めたいのは初期の性格であり、アバターは姿と名前をまとめて決める単位なので、性格の出発点もそこにあるのが自然である。

一方で、性格は夜に natsumi 自身が育てる記憶である。ADR 0057 は、アバターは基本的に切り替えず、記憶はアバターごとに分けないと決めている。

## Decision

### アバターのディレクトリに省略可の `personality.md` を足す

- アバターのディレクトリに `personality.md`（Markdown）を置けるようにする。省略できる。
- 起動時にアバターと一緒に 1 度だけ読む。中身はそのまま持ち、形は問わない。
- 置いてあるのに空（空白だけ）なら、壊れたアバターとして起動を止める。ディレクトリの外を指す（symlink を含む）ときも同じである。他の素材の扱い（ADR 0057）にそろえる。
- 無いのは誤りではない。`natsumi avatar check` は「サーバーの既定を使うもの」に `personality.md` を挙げる。
- アプリには渡さない。読むのはサーバーだけなので、アプリに配る組にも、その版にも入らない。

### 記憶に `personality.md` が無いときだけ、初期値として写す

記憶のリポジトリの `personality.md` を置く順番は次のとおりとする。

1. 記憶のリポジトリに `personality.md` があれば、何もしない。
2. 旧配置の `personality.md` があれば、それを移す（今までどおり）。
3. アバターに `personality.md` があれば、その中身を写す（config の `avatar.personality` があれば、アバターのものに代えてそれを写す）。
4. どれも無ければ、固定の枠を置く。枠の中の名前は、アバターの表示名にする（例「なつみの性格と話し方をここに書きます。」）。

置いたものは、他の固定のファイルと同じく、起動時のコミットに入る。

### すでにある記憶の性格は上書きしない

- アバターを切り替えても、アバターの `personality.md` を書き直しても、記憶の `personality.md` は変わらない。
- 性格は、夜に natsumi が育てる記憶である。アバターの `personality.md` は出発点であり、以後の正ではない。
  切り替えのたびに入れ替えると、育った分が失われる。ADR 0057 の「記憶はアバターごとに分けない」とも合う。
- 初期値からやり直したいときは、本人が記憶のリポジトリの `personality.md` を消して、サーバーを再起動する。

### 中身は本人が決める

- 組み込みのアバターの `personality.md` の中身は、本人に聞いて決める。聞いていないアバターには置かない。
- アバターを新しく作る手順（`assets/avatars/CLAUDE.md`）の聞き取りに、性格・話し方の初期値（任意）を足す。

### ADR との関係

- ADR 0018
  - 追加: `personality.md` が無いときに置くものに、アバターの `personality.md` を加える。枠の名前をアバターの表示名にする。
  - 保つ: 旧配置からの移動を優先すること。性格を書き換えられるのは夜だけであること。
- ADR 0057
  - 追加: アバターのディレクトリの素材に、省略可の `personality.md` を加える。
  - 保つ: 記憶をアバターごとに分けないこと。切り替えたときの記憶の中の古いものを扱わないこと。

## Consequences

- 本人は、natsumi が最初に持つ性格と話し方を、アバターと一緒に決められる。
- 性格の初期値が効くのは、記憶に `personality.md` が無いときだけである。動いている natsumi のアバターの `personality.md` を直しても、何も変わらない。
  この挙動は `docs/avatar.md` に書く。
- アバターを切り替えると、姿と名前は変わるが、性格は前のアバターのものが残る。本人が記憶の `personality.md` を直すか消すまで続く。
- 写した直後の `personality.md` は、記憶のファイルの長さの上限の検査を通っていない。上限を超えていても起動は止まらず、夜の書き換えのときに検査に当たる。
- 固定の枠の文言が「natsumi」から表示名に変わる。すでにある記憶の枠は書き換えない。
