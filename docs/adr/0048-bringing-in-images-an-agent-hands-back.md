# 0048. 外のエージェントが返事に付けた画像を、サーバーが /work に取り込む

- Date: 2026-09-26
- Status: Accepted

## Context

[ADR 0025](0025-talking-to-outside-agents-over-a2a.md) で「成果物（画像など）は、エージェントが自分の保存領域に置き、URI で渡す。手元に残す必要があれば、なつみのサーバーが取り出して永続領域に取り込む。モデルに取り出させない」と決めた。
けれども `ask_agent` の返事（[ADR 0035](0035-asking-outside-agents-and-hearing-back.md) の `agent_reply` の出来事）は、テキストだけを読み、ファイルやデータを捨てていた。

`yuanying/fraction-agents` に調べもの係を置き、ページのスクリーンショットをなつみに渡すことになった。係の側（汎用ホスト）とは、次の形で受け渡すことを先に決めた。

- 画像ごとに、タスクの完了の返事に A2A の Artifact を 1 つ足す。parts は FilePart 1 つで、A2A 1.0 の線上では `{ url, mediaType, filename }` と書く。Artifact の `description` に、何の画像かを 1 行書く。
- `url` は、係の Agent Card と同じ origin の `/artifacts/<ID>` である。取るには A2A の呼び出しと同じ Bearer の token が要る。無い・違う token は 401、知らない ID と期限切れは 404 になる。
- 1 枚は 10 MiB まで、1 つのタスクに 8 枚まで。係は 7 日（設定で変わる）保持して消す。

手元には次のものがあった。

- `/work` の画像を検査して、サーバー側に写しを取り、`images` の表に記録する部品（[ADR 0044](0044-drawing-with-sdctl-and-posting-images.md)）。
- なつみは `/work` の画像を `view` で見られ、`reply_to_mac` の `images` で本人に見せられる（[ADR 0045](0045-showing-the-owner-images-with-a-reply.md)）。
- token は設定の URL にだけ送る。Agent Card は token なしで取る（ADR 0025、[ADR 0036](0036-a-manual-to-read-and-a-limit-on-waiting.md)）。

## Decision

### 済んだタスクの FilePart を、出来事を作る前に取り込む

- 返事を取りに行って、タスクが済んでいれば（completed）、Artifact の FilePart を並んだ順に取る。取り終えてから、テキストと合わせて 1 つの `agent_reply` の出来事にする。
  聞き返し・失敗・メッセージで即答した返事からは取らない。
- 取れなかった画像があっても、テキストの返事はそのまま渡す。取れなかったことは出来事に書く。

### 取るのは、相手と同じ origin のものだけ

- `url` の origin が、設定の `a2a.agents.<名前>.url` の origin と同じものだけを取る。Agent Card はこの URL から取るので、係が名乗る Agent Card の origin と同じである。
  ほかの origin のもの、URL として読めないものは、取りに行かずに「取らなかった」と書く。token は設定の URL の origin の外へ出ない。
- 取るときは、呼び出しと同じ token のファイルを読み、Bearer で付ける。リダイレクトはたどらない。たどると、token が別の origin に運ばれうるからである。
- 時間の上限は、呼び出しと同じ（30 秒）とする。

### 上限と形式

- 1 枚 10 MiB を超えるものは取らない。`Content-Length` で先に断り、無ければ届いた量で数えて、超えた時点でやめる。
- 1 つの返事から取るのは、並んだ順に 8 枚までとする。9 枚目からは取りに行かない。上限は契約の値で、設定には出さない。
- PNG・JPEG・WebP だけを取る。`mediaType` ではなく、中身で見分ける（ADR 0044 と同じ）。拡張子も中身の形式で付ける。

### 置き場所と写し

- 取った画像は、作業環境の `/work/agents/<相手の名前>/<日時>-<名前>.<拡張子>` に置く。
  - 日時は UTC の `20260924T030000Z` の形で、取り込んだ時刻である。
  - 名前は Artifact の `filename` から、パスの部分と拡張子を除き、英数字・`.`・`_`・`-` 以外を `-` にしたものである。何も残らなければ `image-<何枚目か>` にする。
  - 同じ名前のファイルがあれば、上書きせずに `-2`、`-3` と付ける。
- `/work/agents` とその下は、なつみが作り替えられる場所である。置く前と作った後に、実際のパスが `/work` の中にあることを確かめる。外を指していれば置かず、「取れなかった」と書く。ファイルは新しく作るときだけ書き、既にあるファイルやリンクを通しては書かない。
- 置いた画像は、ADR 0044 と同じく、サーバー側にも写しを取り、`images` の表に記録する。`source` は `/work` のパスである。写しと表の行は、出来事と同じトランザクションで記録する。
- 置き場所と写しの権限は、ほかの `/work` のファイルと同じく、作業環境と共有するグループに読み書きさせる（[ADR 0033](0033-running-on-kubernetes.md)）。

### 出来事に書くこと

- 置いた画像は `images` に、置いたパスと Artifact の `description` の組を並べる。
- 取らなかった画像は `images_not_taken` に、`filename` と、理由の 1 文の組を並べる。理由は、別の origin だった・相手に断られた（401）・相手のところに無い（404。期限切れかもしれない）・つながらない・大きすぎる・画像の形式でない・8 枚を超えた・`/work/agents` が外を指している、などである。
- どちらも、無ければ欄を置かない。テキストだけの返事の出来事は、今までと同じ形である。
- 出来事の本文は、テキストと同じく、なつみに渡すまで `agent_replies` の `files` に置き、渡したら消す（[ADR 0008](0008-single-thinking-loop-and-mac-conversation.md)）。
- ログには、相手の名前と、取った数・取らなかった数だけを出す。URL・ファイル名・説明は出さない。

### なつみの手引き

- `/manual/ask-agent.md` に、返事に `images` があれば `view` で見て、本人に見せるなら `reply_to_mac` の `images` にそのパスを並べる、と書く。
  `description` も相手の言葉であって、本人の言葉ではない。

### ADR との関係

- ADR 0025
  - 具体化: 成果物の URI を取り込む形。取り込む先は `/work/agents/<相手>/`、写しは ADR 0044 の `images` の表。
- ADR 0035
  - 追加: `agent_reply` の出来事の `images` と `images_not_taken`。

## Consequences

- なつみは、調べもの係のスクリーンショットなどを `view` で見て、そのまま本人に見せられる。モデルに URL や token を扱わせずに済む。
- 画像は `/work` と写しの 2 か所に残る。`/work` のものはなつみが消してよく、写しは会話の画像と同じく消さない。data directory はその分増える。
- 取り込みは返事を取りに行く一巡の中で行う。画像が多く大きいと、その一巡とほかの相手の返事が、その分遅れる。
- 係の保持の期間を過ぎた返事は、再起動などで取り直しても画像を取れない。出来事には 404 として書く。
- 取り込んでいる途中でサーバーが止まると、そのタスクは再起動の後にもう一度取りに行き、画像を置き直す。`/work` には前に置いた分が残り、名前には `-2` が付く。
- `/work/agents` の確かめと書き込みの間になつみがリンクを差し込む競合は、完全には防げない。`wx` で新しいファイルだけを作るので、既存のファイルを書き換えることは無い。
