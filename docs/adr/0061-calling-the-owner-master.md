# 0061. オーナーを「マスター」と呼び、誰が誰にを名前で書かせる

- Date: 2026-09-30
- Status: Accepted

## Context

natsumi が読む文（システムプロンプト、ツールの説明と結果、夜の振り返り、一行メモの頼み方、compaction の指示、記憶の整理係への指示、マニュアル）は、
オーナーを一貫して「本人」と呼んでいた。

natsumi が読み書きするものには、何人もの人が出てくる。オーナー、送信役のポッポさん、外のエージェント、Slack のチャンネルの人たちである。
「本人」は、文脈によっては「その話の当人」とも読める。一行メモ・日記・記憶に「本人」「自分」「あの人」と書かれると、
後から読み返したときに、誰が誰に何をしたのかが分からなくなる。

また、Slack の記録には発言者が Slack の表示名で並ぶ。オーナーが Slack の名前とプロンプトの「本人」の 2 つで記憶に残ると、読み返したときに別人に見えうる。

## Decision

### オーナーは「マスター」と固定で書く

- natsumi が読む文の「本人」を、すべて「マスター」にする。システムプロンプトの冒頭で一度、「あなたのオーナー（持ち主）であるマスター」と役割を示す。
  記憶の整理係にも、natsumi のオーナーを記憶ではマスターと呼ぶことを一度示す。
- 呼び名は設定に持たない。マニュアルはコードに固定のファイルであり（[ADR 0036](0036-a-manual-to-read-and-a-limit-on-waiting.md)、
  [ADR 0056](0056-the-manual-index-and-the-workspace-commands-in-the-prompt.md)）、そこにも「マスター」と書く。
  呼び名を設定で変えられるようにすると、プロンプトとマニュアルで呼び名が食い違う。
- ツール名、JSON のキー、出来事の種類の名前（`notify_owner`、`unacknowledged_notices` など）は変えない。
- 変えるのは natsumi（と整理係）が読む文だけである。ポッポさんの判定の問い、アプリやダッシュボードの表示、人向けの文書は変えない。
  ポッポさんが natsumi に返す結果の文は natsumi が読むので、「マスター」にする。

### 誰がマスターかは、natsumi が記憶から判断する

- Slack などの記録に、オーナーの発言の印は付けない。設定にもオーナーの Slack のユーザー ID を持たない。
- どの名前の人がマスターかは、natsumi が会話から知り、記憶に書いて判断する。
  マスターだと分かっている人は、Slack などでの名前ではなく「マスター」と書くように指示する。対応は記憶に残す。

### 登場人物は記憶に任せる

- マスター、ポッポさん、外のエージェント、Slack の人たちを、どこにどう書くか（ファイルの置き場所や形）は示さない。
  natsumi と整理係（[ADR 0055](0055-a-memory-curator-at-night.md)）に任せる。
- すでにある記憶のファイル（オーナーについて書いたものなど）は、コードでは触らない。扱いも natsumi に任せる。

### 一行メモ・日記・記憶は、呼び名で主語と相手を書く

- 記憶の決まりの節（日記を含む）と一行メモの頼み方に、「『自分』『本人』『あの人』は使わず、マスター・あなたの名前・ポッポさん・Slack の名前などの呼び名で、
  誰が誰に何をしたかを書く」を 1 文で足す。整理係への指示にも、整理係から見た表示名で同じ文を足す。
- natsumi 自身の一人称（セリフの話し方）は変えない。決まりが対象にするのは、後で読み返す記録である。
- 一行メモの 100 字の上限は変えない。
- この決まりの文には natsumi の表示名を入れない。一行メモの頼み方は固定の文であり、アバターの表示名（[ADR 0057](0057-an-avatar-directory-named-in-the-server-config.md)）で変わらないようにする。

### 一行メモの頼み方は、タグで見分ける

- 一行メモの頼み方の文が変わる。これまで、サーバーはこの文と完全に一致するものを一行メモの頼み方として見分けていた（畳む処理、ダッシュボード、集計）。
- session と記録には、変える前の文が残る。完全一致のままでは、変える前のターンが畳まれず、ダッシュボードでも一行メモとして表示されない。
- `<turn_memo>` で始まり `</turn_memo>` で終わる user のメッセージを、一行メモの頼み方として見分けることにする。出来事は `<events>` で包まれて届くので、取り違えない。

### ADR との関係

- [ADR 0047](0047-folding-ended-turns-with-a-memo.md)
  - 変更: 一行メモの頼み方を、文の完全一致ではなくタグで見分ける。
  - 保つ: 頼み方が固定の 1 文であること。
- [ADR 0055](0055-a-memory-curator-at-night.md)
  - 追加: 整理係にも、オーナーの呼び名と書き方の決まりを示す。
  - 保つ: 整理係は natsumi ではなく、誰とも話さないこと。

## Consequences

- 一行メモ・日記・記憶で、オーナーが「マスター」として、ほかの人が呼び名で書かれるようになる。効果は、本番で数日分の一行メモと日記をダッシュボードで見て判断する。
- すでにある記憶には「本人」の書き方が残る。natsumi と整理係が書き直すまで、同じ人が「本人」と「マスター」の 2 つで記憶に残る。
- システムプロンプトとツールの説明が変わるので prefix が動く。入れた日は、走っている session のキャッシュが夜の切り替えまで効かない
  （[ADR 0019](0019-a-workspace-not-a-memory-tool.md)）。
- 一行メモの頼み方は、今後文を変えても、タグを保つ限り前の記録と一緒に見分けられる。
