# 0078. 会話のウインドウと設定を普通のウインドウの層に置く

- Date: 2026-10-12
- Status: Accepted

## Context

[ADR 0010](0010-mac-app-structure.md) は、会話にかかわる表示をすべてキャラクターと同じ層のパネル
（`.nonactivatingPanel`、level `floating`、`canJoinAllSpaces` と `fullScreenAuxiliary`）にした。
最初の版で会話欄を通常のウインドウにしたところ、全画面表示のアプリの上に出ず、開くとアプリが前面になって
使っていたアプリからフォーカスを奪ったためである。[ADR 0021](0021-the-input-and-the-history-in-one-window.md) の
会話のウインドウも、この層を引き継いだ。

Mac から会話にファイルを添えられるようになり（[ADR 0071](0071-attaching-files-to-a-chat-message.md)）、
クリップのボタンでシステムのファイル選択のダイアログを出すと、会話のウインドウがその上に浮かんで使いづらかった。
本人は、会話のウインドウは普通のウインドウと同じでよく、常に前にいるのはキャラクターだけでよいと決めた。
ただし、ショートカットでウインドウを出したときは、裏にいても前に出てほしい。続けて、設定の窓も普通のウインドウにすると決めた。

## Decision

**会話のウインドウを普通のウインドウの層（level `normal`）に置く。** ほかのアプリのウインドウがその上に来てよい。
常にほかのウインドウの上に浮かぶのは、キャラクター・吹き出し・知らせの束（舞台）だけである。

- **自分で呼んだときは前に出す。** ショートカット（[ADR 0023](0023-a-global-shortcut-for-the-conversation-window.md)）、
  メニューの「話しかける」「履歴を開く」、吹き出しの「続きは履歴で」は、ウインドウが出ていて裏にいても、前に出して入力欄に焦点を移す。
  キャラクターのクリックは今までどおり、出ていれば消し、出ていなければ出す。
- **ウインドウの中をクリックしたときも前に出す。** アプリは前面にならないので（`.nonactivatingPanel` のまま）、
  key になったときにウインドウ自身が前に出る。
- **Space は今いるところに出す。** すべての Space に貼り付けるのをやめ（`canJoinAllSpaces` を外す）、呼んだときに
  今の Space へ移す（`moveToActiveSpace`）。`fullScreenAuxiliary` は残し、全画面表示のアプリの上にも呼べば出る。
- アプリを前面にしない（`.nonactivatingPanel`）こと、key になれること、最初のクリックで効くこと、⌘W・⌘L をウインドウ自身が受けることは変えない。
- **設定の窓も同じにする。** 普通のウインドウの層に置き、今の Space に出し、開くたび（メニューの「設定…」など）と中をクリックしたときに前に出す。
- 画像の拡大の窓は、今回は変えない（キャラクターと同じ層のまま）。

## Consequences

- ファイル選択のダイアログ（アプリを前面にして出す）が、会話のウインドウの上に出る。
- ほかのアプリを使うと、会話のウインドウはその裏に回る。読み返したいときはショートカットかメニューで前に出す。
- ADR 0010 の「会話にかかわる表示をすべてキャラクターと同じ層のパネルにする」「設定はキャラクターと同じ層のパネルに出す」と、
  ADR 0021 §2 の「層・Space・全画面の扱いは今の履歴のパネルと同じ」は、会話のウインドウと設定についてこの ADR で置き換わる。
- 全 Space に出ていたウインドウが、呼んだ Space に移るようになる。別の Space に移ると、そこには見えない。
